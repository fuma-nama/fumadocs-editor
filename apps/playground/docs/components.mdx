# Editing MDX components

Registered components render as the real component, and each editable area
is a proper region. Type `/` on an empty line to insert blocks and components.

<Callout type="warn" title="Heads up">
  This callout's title and body are both editable. Click the icon to change its **type**, or press
  `Cmd-.` to open the options behind the ⋯ handle.
</Callout>

Code fences highlight as you type, and the language is one click away:

```ts title="editor.ts"
import { MdxEditor } from "@fumadocs-editor/ui";

export function render(value: string) {
  const editor = new MdxEditor({ defaultValue: value });
  return editor.getMarkdown();
}
```

Cards decompose into structured, editable items. Select some text to get the
formatting bubble; its component chip edits the card's link and other props:

Multi-part components port 1:1 too. Steps keep their numbered rail, and
`Cmd-Enter` starts the next one mid-thought:

<Steps>
  <Step>

    Add `@fumadocs-editor/ui` to your project.

  </Step>
  <Step>

  </Step>
</Steps>

File trees are built like a list: `Enter` adds a row, `Tab` toggles it into a
folder, `Alt-arrows` reorder, and the icons are drag handles:
