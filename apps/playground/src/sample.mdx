# Editing MDX components

Registered components render as the **real component** — each editable area
is a proper region, not a generic code block.

<Callout type="warn" title="Heads up">
  This callout's title and body are both editable. Try changing the **type**
  from the toolbar that appears on hover.
</Callout>

Code fences highlight as you type, and the language is one click away:

```ts title="editor.ts"
import { MdxEditor } from '@fumadocs-editor/ui';

export function render(value: string) {
  const editor = new MdxEditor({ defaultValue: value });
  return editor.getMarkdown();
}
```

Cards decompose into structured, editable items. Open the **Attributes**
popover on a card to edit its link and other props:
