# Editing MDX components

Registered components render as the **real component** — each editable area
is a proper region, not a generic code block.

<Callout type="warn" title="Heads up">
  This callout's title and body are both editable. Try changing the **type**
  from the toolbar that appears on hover.
</Callout>

Cards decompose into structured, editable items:

<Cards>
  <Card title="Getting Started" href="/docs">Set up your first project.</Card>
  <Card title="Components" href="/docs/components">Browse the component library.</Card>
</Cards>

Everything else stays plain markdown, and unedited blocks round-trip
byte-for-byte.
