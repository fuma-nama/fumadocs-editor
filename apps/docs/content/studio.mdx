Studio is the editor as a command. Run it in your Fumadocs app:

```bash
npx @fumadocs-editor/studio
```

It opens a browser with your documents and a file list:

- edits save to disk, and changes on disk merge in ([Sync](/sync))
- the [file tree](/file-tree) creates, deletes and reorders pages
- `?collab` in the URL turns on [collaboration](/collab) for that tab

<Callout type="info">Studio needs Node 24 or later.</Callout>

## Keyboard

| Keys  | Does                                                 |
| ----- | ---------------------------------------------------- |
| `⌘K`  | search files and actions (theme, collab, MDX source) |
| `⌘S`  | save now                                             |
| `Esc` | close the file list, when focused                    |

The file list has its own [shortcuts](/file-tree#keyboard).

## Flags

| Flag              | Default                                 |
| ----------------- | --------------------------------------- |
| `--root <dir>`    | `content/docs`, `content`, then the cwd |
| `--config <file>` | `fumadocs-studio.config.ts`             |
| `--port <n>`      | `5180`                                  |
| `--host`          | listen on all addresses                 |
| `--no-open`       | do not open the browser                 |

### Server options

The config also runs in the browser. Put anything Node-only (a JWT library,
a Vite plugin) in a separate file, and reference it with `server`:

<include meta='title="studio.server.ts"'>../examples/studio-server.ts</include>

`server` takes every [sync server option](/server#options) except `root`,
plus `vite`:

- `authenticate` guards Studio ([Auth](/auth)).
- `setup` reaches the server, for `connections()` and `onChange`
  ([Sync Server](/server#reach-the-server-with-setup)).
- `storage` replaces the folder on disk ([Storage](/server#storage)); `root`
  and `--root` are then ignored.

## Auth

Without `authenticate`, anyone who can reach the port can edit. With it:

- the credential comes from `?token=` in the URL by default
- override where it comes from with `auth`

See [Auth](/auth) for writing the hook.
