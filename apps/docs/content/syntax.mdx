## One syntax

The editor understands two props: `components` (registered specs) and
`syntax` (parse-level switches). Together they drive parse, serialize, and
edit.

Anything outside that syntax is verbatim: it round-trips byte-for-byte and
is edited as source. Turning a feature off does not break a document; those
constructs stop being editable in place.

## Options

| Option            | Default                                          | Turns on                                |
| ----------------- | ------------------------------------------------ | --------------------------------------- |
| `headingSuffixes` | `true`                                           | fumadocs heading suffixes as attributes |
| `directives`      | off (`true` once `admonitionSpec` is registered) | the `:::` admonition dialect            |
| `math`            | off                                              | `$…$` / `$$…$$` TeX math                |

Dialects are off by default: they change how existing text parses (`$…$`,
`:::` lines). Turn one on only if that content is yours.

### Heading suffixes

`## Title [#custom-id]`, `[!toc]`, and `[toc]` become heading attributes
(chips, edited from the turn-into menu), not literal prose. On by default:
it only applies inside headings.

### Directive admonitions

`:::warn[Title]` is an editable admonition. Registering the spec turns the
dialect on:

```ts
const components = [...fumadocsUiComponents, admonitionSpec];
```

Admonitions stay `:::`; `<Callout>` stays JSX. No implicit conversion.
Unknown names, rich labels, nested unknown directives fall back to verbatim.

### Math

`syntax={{ math: true }}` turns `$x^2$` and `$$…$$` into math nodes: editable
source with a KaTeX preview. KaTeX loads lazily on first math. Delimiters
are preserved (`$$x$$` stays `$$x$$`). An emptied inline formula is dropped
(bare `$$` would not re-parse).

### Files fences

Register `filesFenceSpecs` to edit canonical ` ```files ` tree fences with
the same UI as JSX `<Files>`. A fence stays a fence; JSX stays JSX. Non-canonical
fences (loose indent, multiple roots) stay plain code blocks.

## Deferred syntaxes

`<CodeBlockTabs>`, primitive (non-fumadocs) `<Tabs>`, and footnotes are not
structurally editable yet. Verbatim fallback: source cards, byte-for-byte.
