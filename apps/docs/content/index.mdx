## Introduction

Fumadocs Editor is a visual editor for MDX documents. It renders your content —
prose, code, tables, and your MDX components — as an editable page instead of
source text, while keeping the file the source of truth:

- **Lossless round-trip**: blocks you didn't touch are emitted byte-for-byte,
  so a one-line edit produces a one-line diff. Anything the editor doesn't
  understand is preserved verbatim instead of being reformatted or dropped.
- **Spec-driven components**: the fumadocs-ui components (Callout, Cards,
  Tabs, Files, …) are editable in place, and [your own components](/components)
  plug in with a small spec.
- **Instant open**: the document paints statically first and the editing
  runtime hydrates behind it — no keystroke is lost while it loads.

It ships as three packages:

## Installation

```bash
npm install @fumadocs-editor/ui
```

React 19 is required. The editor is a client component — render it inside a
`'use client'` boundary in server-rendered apps.

## Styles

The editor is styled with Tailwind CSS v4 and the fumadocs `fd-*` design
tokens. Import the preset after Tailwind in your global stylesheet:

```css title="app.css"
@import "tailwindcss";
@import "@fumadocs-editor/ui/css/preset.css";
```

The preset registers the `--color-fd-*` tokens (with the fumadocs `neutral`
theme as defaults) and tells Tailwind to scan the package, so the editor's
utility classes are generated by your build. Inside a Fumadocs site your
site theme already defines those tokens and simply wins.

## Theming

The `fd-*` tokens key off a `.dark` class, so inside a Fumadocs site (or any
`next-themes` setup) the editor follows the site theme with no wiring. In a
standalone app, wrap it in the bundled provider:

<include meta='title="standalone.tsx"'>../examples/theming.tsx</include>

`EditorThemeProvider` tracks a `light | dark | system` choice, persists it to
`localStorage`, and applies the class on a wrapper element. To pin one editor
to a fixed look regardless of the surroundings, pass `theme="light"` or
`theme="dark"` directly.
