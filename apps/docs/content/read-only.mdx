## The `editable` prop

`editable={false}` shows the document read-only: no typing, no mutating
chrome (slash menu, bubble and block menus, mobile bar, drag handles).
Selection and copy still work. The raw MDX tab is read-only too. The prop
is live; flipping it does not remount.

Plain TipTap passthrough. It has no opinion about _why_: viewer role,
published snapshot, checked out by someone else.

A read-only user who tampers with the client and types anyway changes
nothing. The server refuses the writes. Under [collab](/collab), their Y
updates are dropped; they still receive everyone else's. `editable` is UI,
not the security boundary.

`onOpen` fires the same way with `collab` on.
