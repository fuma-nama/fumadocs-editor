### Initial release

A WYSIWYG editor for Fumadocs MDX content.

- **`@fumadocs-editor/ui`** — the React editor component: prose, code,
  tables, and MDX components edited in place, with slash-menu insertion, a
  selection toolbar, a touch bar on mobile, and a lossless round-trip back to
  source (untouched blocks are emitted byte-for-byte). Custom components plug
  in with a spec plus a lightweight renderer.
- **`@fumadocs-editor/core`** — the headless engine: MDX parsing into a
  TipTap document, incremental serialization, the component spec model, and
  the dialect switches (math, directive admonitions, files fences, heading
  suffixes).
- **`@fumadocs-editor/sync`** — the file-system mirror: autosave with
  compare-and-swap writes, block-level three-way merge of external edits,
  collaborative editing with a server-authoritative Y.Doc, and a
  server-enforced auth layer with per-document scopes.
